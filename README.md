# Sprint_6

Автотесты для сервиса аренды самокатов.

## Стек

* Python
* Pytest
* Selenium WebDriver
* Allure

## Структура проекта

* `tests/` — тесты
* `pages/` — Page Object классы страниц
* `locators/` — локаторы элементов
* `data/` — тестовые данные
* `conftest.py` — фикстуры
* `constants.py` — константы проекта

## Реализованные проверки

### Главная страница

* проверка ответов в разделе «Вопросы о важном»

### Заказ самоката

* оформление заказа через верхнюю кнопку «Заказать»
* проверка успешного создания заказа
* параметризация тестов двумя наборами данных

### Логотипы

* переход на главную страницу по логотипу «Самокат»
* открытие новой вкладки по логотипу Яндекса

## Запуск тестов

```bash
python3 -m pytest -v
```

## Генерация Allure-отчёта

```bash
python3 -m pytest --alluredir=allure_results
```

```bash
allure serve allure_results
```
